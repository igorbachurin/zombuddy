# Catalog reports

Catalog refresh reports are committed beside the generated catalog. A clean report has no missing translations, unexpected duplicate IDs, unmatched capability groups, or unknown qualifying entries.

The checked-in Build 42.20 baseline was generated from the installed public-branch game media. It contains 404 unique entries: 120 skill books, 87 recipe-literature entries, 110 recipe-teaching seed packets, 62 progression VHS tapes, and 25 tool capabilities. `data/catalog-report-42.20.0.json` records the source audit and catalog diff.
